Core Features

100% local, zero upload, full privacy. Everything runs inside your browser.

1. 100% Local Privacy Compression

All parsing, compression, and rendering happen locally in your browser. No file data is ever transmitted to any server.

2. Three Compression Modes

  • Light — Almost lossless quality for formal documents
  • Balanced — Best quality/size ratio for daily use
  • Extreme — Maximum size reduction for uploading

3. Batch Processing

Upload multiple PDFs at once, process them in parallel, and download individually or as a single ZIP file.

4. Large File Support

Supports PDFs up to 200MB per file — perfect for high-resolution scans and multi-page documents.

5. Cross-Device Compatible

Works on desktop, tablet, and mobile. No app installation needed.

6. Smart Memory Management

Built-in memory optimization prevents crashes and keeps performance smooth even with large files.
