Split a PDF without sending it anywhere

Choose how you want the pages cut. Each output file is built by copying pages, so the text in them is still selectable.

Click or drop one PDF file here
Pick a mode above, then press Split PDF

Limits worth knowing before you start. One file per page is capped at 50 pages, and a single split run is capped at 50 output files. Ranges that fall outside the document are ignored rather than reported — check the page count in the output if a range looks wrong.

What splitting does not do. It does not re-encode anything, so a 40 MB input split into four parts still adds up to roughly 40 MB. It also does not remove metadata: each output keeps the author, title and XMP block of the original.
