Merge PDF files without uploading them

Pages are copied from one document to another, not re-rendered. Text stays selectable and links keep working.

Click or drop 2 or more PDF files here
Order matters — move files up or down before merging

What merge does and does not change. This tool copies page objects from your files into a new document. Nothing is re-encoded, so selectable text, embedded fonts, vectors, links and form fields survive the merge. The output is the same size as the sum of the inputs, minus a small amount of duplicated structure.

Encrypted files stop the merge. A password-protected PDF has to be unlocked before its pages can be copied. If one file fails, the whole batch stops and names the file — it does not silently skip it.
