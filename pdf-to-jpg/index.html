Each page becomes an image at the resolution you pick. Useful for slides, forms and anywhere a PDF gets refused.

Pick format and resolution above — up to 100 pages per run

What you lose in the conversion. The output is a bitmap. There is no text layer inside it, so nobody can select, search or copy the words afterwards, and screen readers cannot read it. If the PDF needs to stay searchable, this is the wrong tool.

Resolution decides the file size. A 72 DPI page is fine on screen and blurry in print. 144 DPI is the everyday setting. 216 DPI is near print quality and produces files several times larger. Every page renders separately, so a 60-page document at high resolution will take a while and use real memory.
