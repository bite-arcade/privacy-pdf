# Contributing

Thanks for your interest in contributing! This project is a small, open-source
collection of browser-based mini-games, and community help is welcome.

## Before you start

- Please make sure you have read and understood the project `README`.
- This project follows the **MIT license**; by contributing, you agree that your
  contributions will also be released under the MIT license.

## 🐛 Bug Reports

When submitting a bug report via GitHub Issues, please include:

1. A clear title describing the problem.
2. Steps to reproduce (which page / game, what you clicked).
3. Your browser and device (e.g. Chrome 124 on iOS 17).
4. Screenshots or a short screen recording if possible.

## 💡 Suggestions & New Games

- Suggest new game ideas or improvements through Issues.
- Want to add a game? Open a Pull Request with the game assets and a short
  description of how to play.

## 🔒 Security & Privacy

This project is committed to **100% client-side, no-upload processing**.

- For security-related issues, **do not open public GitHub issues**. Send
  details privately to the maintainer instead.
- Do not introduce any code that uploads user files or sends data to third-party
  servers.

## 📦 Pull Requests

1. Fork the repository and create a feature branch.
2. Keep changes focused and minimal.
3. Test locally (see README → "How to Use") before submitting.
4. Open a PR with a clear description of what changed and why.

We review contributions on a best-effort basis. Thank you for helping make the
project better! 🎮
