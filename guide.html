User Guide & FAQ

Simple steps to compress your PDF files safely and locally. Below is the complete usage guide and common questions.

How to Use (3 Simple Steps)

  1. Select Compression Mode: Choose Light, Balanced, or Extreme compression according to your needs.
  2. Upload PDF Files: Click the upload area or drag PDF files into the page. Multiple files are supported.
  3. Download Results: After automatic compression, download single files or batch download all files via ZIP package.

Frequently Asked Questions

1. Are my files uploaded to the server?

No. All compression calculations are completed inside your local browser. Your files will never be uploaded, transmitted, or stored on any remote server.

2. Will the compressed PDF lose quality?

Different modes have different balance strategies. Light mode retains almost all original quality. Balanced mode balances size and clarity. Extreme mode pursues the smallest volume with acceptable clarity.

3. How many files can I process at one time?

Free version supports limited batch processing. Pro version unlocks unlimited batch quantity and faster processing speed.

4. Is this tool free to use?

Basic local PDF compression functions are permanently free. Advanced unlimited batch, ultra compression and enterprise adaptation belong to Pro membership privileges.

5. Does the tool collect my personal data?

We do not collect file content, do not record user behavior, and do not track personal information. Only necessary local cookies are used to maintain basic page functions.

Which tool do I need?

The guide above covers compression only. If your problem is something else, the list below maps the job to the page.

  • Too many separate files to send as one → Merge PDF
  • One long file that has to become several → Split PDF
  • A page that has to arrive as an image → PDF to JPG
  • Text that must stop being copyable → Redact PDF
  • Author name, software, or timestamps still attached to the file → Remove PDF metadata
