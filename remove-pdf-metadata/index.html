Why one pass is not enough

The Info dictionary is a small key-value block near the end of the file. Clearing it removes Title, Author, Subject, Keywords, Creator and Producer. But PDF 1.4 and later also carry an XMP packet — an XML block attached to the document catalog — and that block frequently repeats the author, the tool that produced the file, and timestamps. A cleaner that touches only the Info dictionary leaves the packet untouched, and so does the compression pipeline on this site: it clears the Info dict but keeps XMP.

This page reads both, prints both, and removes both. After saving, the output is reopened and the fields are read again, so you can see that the removal actually took rather than trusting a success message.

What it does not touch: the text of the document, embedded images, annotations, or the file's structure. Metadata removal is not redaction — if a name appears in the body text, it stays there.

Metadata questions

What is XMP metadata in a PDF?

XMP is an XML block attached to the document catalog, separate from the Info dictionary. It usually repeats the author name, the software that produced the file, and timestamps. A cleaner that touches only the Info dictionary leaves this block intact.

Does this tool remove XMP that other cleaners leave behind?

Yes. This page reads the Info dictionary and the XMP packet, prints both, and removes both. After saving, the output is reopened and every stream is read again, so leftovers are reported instead of assumed gone.

Does removing metadata redact the text of the document?

No. Metadata removal deletes hidden document properties. Names, emails or account numbers written in the body text stay in the body text. Use Redact PDF for that, then check what is left.

Are my files uploaded to a server?

No. Inspection and removal both run in your browser. The file is read from disk, processed in memory, and saved back to disk. Nothing is sent to a server.
